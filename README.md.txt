# 🚲 Bike-Share Case Study (Google Data Analytics Capstone)

## 📌 Objective
Analyze how casual riders and annual members use Cyclistic bikes differently.

## 🛠 Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Google Colab
- GitHub

## 📊 Key Findings
- 60% rides by members, 40% by casual riders
- Casual riders take longer trips on weekends
- Members ride more on weekdays (commute pattern)
